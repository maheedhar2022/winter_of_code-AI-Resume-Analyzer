# AI Resume Analyzer

## Problem Statement
Recruiters receive hundreds of resumes for a single job posting, making manual screening time-consuming and inefficient. This project aims to automate the initial resume screening process using machine learning and natural language processing.

## Solution
The AI Resume Analyzer compares a candidate’s resume with a job description and provides:
- Resume–Job match score
- Extracted skills
- Missing skills
- Improvement suggestions

## Tech Stack

**Frontend**
- React.js

**Backend**
- FastAPI (Python)

**Machine Learning**
- scikit-learn
- TF-IDF Vectorization
- Cosine Similarity


## Features
- Upload resume (PDF)
- Paste job description
- ML-based matching score
- Skill gap analysis

## Future Scope
- Authentication
